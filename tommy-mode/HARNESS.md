# Grok Build harness for tommy-mode

Host map. grok does not load it as a skill.

| Need | Grok primitive |
|---|---|
| Slash | `/tommy-mode` |
| Spawn | none. Overlay uses `pstack:<role>` from the pstack plugin. |
| Skill order | pstack, then user, then this plugin |
| Hooks | none |
| Commands | none. Do not clone `/tommy-mode` into `commands/`. |
